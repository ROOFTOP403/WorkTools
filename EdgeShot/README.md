# EdgeShot

EdgeShot은 Windows 알림 영역 또는 화면 가장자리의 작은 플로팅 버튼에서 바로 영역 캡처를 시작하는 경량 도구입니다.

## 1.2.3 수정 사항

- Release 빌드에서 embedded PDB와 로컬 소스 경로 제거
- 빌드 산출물, Library 임시 파일, 사용자 화면 캡처를 제외하는 `.gitignore` 추가
- GitHub 및 회사 배포 전 소스 위생 검사 보강

## 1.2.2 수정 사항

- Windows 탐색기에서 표시되는 EXE 아이콘을 청록색 채운 카메라 실루엣으로 지정
- 16·20·24·32·40·48·64·128·256px PNG 프레임을 하나의 ICO 리소스에 포함
- 런타임 플로팅 버튼과 트레이 동작은 변경하지 않음

## 1.2.1 수정 사항

- 설정 화면에서 PNG 저장 폴더를 확인하고 `찾아보기...`로 변경 가능
- 기존 설정처럼 저장 폴더가 비어 있으면 바탕 화면을 기본값으로 사용
- 영역 및 전체 화면 캡처 모두 선택한 PNG 폴더를 공통으로 사용

## 1.2.0 수정 사항

- 플로팅 버튼과 트레이의 우클릭 메뉴에 `영역 캡처`와 `전체 화면 캡처` 추가
- 전체 화면 하위 메뉴에서 주·보조 모니터를 장치명과 해상도로 구분하고, 다중 모니터에서는 `모든 모니터`도 선택 가능
- 선택된 모드와 전체 화면 대상 앞에 체크 표시하고 재시작 후에도 선택 유지
- 기본값은 영역 캡처이며, 모드 선택 후 플로팅 버튼·트레이 왼쪽 클릭은 선택된 모드로 실행
- 전체 화면 결과도 기존 클립보드 복사 및 선택적 바탕화면 PNG 저장과 동일하게 연동
- 설정 화면 하단에 `© RoofTopStudio403` 표시

## 1.1.4 수정 사항

- 승인된 트레이 A안에 맞춰 배경 없는 채운 카메라 실루엣과 투명한 렌즈 구멍 적용
- 16px 공간에서 약 14px 폭을 사용하도록 점유 크기를 키워 주변 트레이 아이콘과 균형 조정
- 플로팅 버튼 디자인과 동작은 1.1.3 상태 그대로 유지

## 1.1.3 수정 사항

- 작은 크기의 소수점 좌표에 `PenAlignment.Inset` 선을 그려 변마다 픽셀 커버리지가 달라지던 테두리를 균일한 채움 링으로 교체
- 4배 해상도에서 렌더링한 뒤 축소하여 둥근 모서리와 카메라 윤곽의 안티앨리어싱 품질 개선
- 시스템 트레이는 배경과 외곽 테두리를 제거하고 청록·코랄 카메라 윤곽만 표시

## 1.1.2 수정 사항

- 승인된 B안에 맞춰 평상시 반투명 배경 바깥에 선택 색상의 선명한 1px 둥근 테두리 추가
- 청록·코랄 카메라 윤곽과 per-pixel alpha 합성은 유지
- 호버 상태는 기존 불투명 색상 배경과 흰색 카메라 형태를 그대로 유지
- 카메라 픽셀 표현은 유지하면서 여백 확보를 위해 버튼 기준을 FHD 28px, QHD 36px, 4K 54px로 조정

## 1.1.1 수정 사항

- 합의 시안의 01 청록 및 03 코랄 색상과 카메라 비율에 맞춰 다시 조정
- 겹친 도형 대신 하나의 연속된 카메라 외곽 경로를 사용해 16px/24px/32px 클리핑 방지
- 고정 회색 배경과 창 전체 불투명도 방식을 제거하고 `UpdateLayeredWindow` 기반 per-pixel alpha 적용
- 평상시에는 알파 48/255의 색상 배경과 불투명 카메라 윤곽, 호버 시에는 불투명 배경과 흰 윤곽 사용

## 1.1.0 수정 사항

- 플로팅 버튼을 평면적인 둥근 사각형과 간결한 카메라 윤곽선으로 변경
- 평상시 반투명 배경과 색상 아이콘, 마우스 오버 시 선명한 배경과 흰색 아이콘 적용
- 설정에서 청록(기본)과 코랄 색상 선택 및 저장
- 시스템 트레이 카메라 아이콘의 윤곽선 색상도 선택한 테마와 연동

## 1.0.2 수정 사항

- 작은 크기에서도 알아보기 쉬운 카메라 모양 시스템 트레이 아이콘 적용

## 1.0.1 수정 사항

- .NET 9에서 지원되지 않는 화면 복사 연산 조합 때문에 캡처가 시작되지 않던 문제 수정
- 테두리 없는 전체화면 창 위로 선택 오버레이를 올리는 전경/최상위 처리 보강
- 플로팅 버튼 우클릭 메뉴 추가
- 앱이 직접 여는 설정 및 오류 창을 플로팅 버튼이 있는 모니터에 우선 배치
- 캡처 단계 진단 로그 추가

## 기능

- 트레이 아이콘 또는 플로팅 버튼 왼쪽 클릭 → 현재 선택된 영역/전체 화면 모드로 캡처 → 클립보드 복사
- 선택 옵션으로 지정한 폴더에 PNG 동시 저장(기본값: 바탕 화면)
- 선택 옵션으로 Windows 로그인 시 자동 시작
- 다중 모니터 및 Per-Monitor DPI V2 지원
- 플로팅 버튼을 다른 모니터로 자유롭게 이동하고 위치 저장
- 트레이 또는 플로팅 버튼 우클릭으로 캡처 모드와 대상 모니터 선택, 설정, 종료 메뉴 열기
- 캡처 전에 버튼을 숨기고 화면을 동결하여 결과 이미지에서 EdgeShot UI 제외
- QHD(1440p)에서 36px, 화면 높이에 따라 28~54px로 버튼 크기 조절
- 단일 EXE 자체 포함 배포

편집기, OCR, 클라우드 동기화, 광고, 로그인 기능은 포함하지 않습니다.

## 사용법

1. `EdgeShot.exe`를 실행합니다.
2. 기본 영역 캡처는 알림 영역의 EdgeShot 아이콘 또는 플로팅 버튼을 클릭한 뒤 캡처할 영역을 드래그합니다.
3. 전체 화면 캡처는 아이콘을 오른쪽 클릭해 모드와 대상 모니터를 선택한 뒤 왼쪽 클릭합니다. 영역 선택 중에는 `Esc` 또는 오른쪽 클릭으로 취소할 수 있습니다.
4. 이미지는 즉시 클립보드에 들어갑니다.
5. 옵션은 트레이 아이콘을 오른쪽 클릭한 뒤 **설정...**에서 변경합니다.

설정 화면을 바로 열어 실행하려면 `EdgeShot.exe --settings`를 사용할 수도 있습니다.

플로팅 버튼은 드래그하여 옮길 수 있습니다. 설정과 위치는 `%LOCALAPPDATA%\EdgeShot\settings.json`에 저장됩니다. 자동 시작은 기본적으로 꺼져 있으며, 설정에서 사용자가 직접 선택한 경우에만 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`에 등록됩니다.

캡처 시작과 오버레이 전경 전환 진단은 `%LOCALAPPDATA%\EdgeShot\EdgeShot.log`에 기록됩니다. 전체화면 게임에서 문제가 반복되면 이 파일의 마지막 캡처 항목으로 화면 복사 성공 여부와 오버레이 전경 전환 여부를 구분할 수 있습니다.

EdgeShot이 직접 여는 설정 및 오류 창은 플로팅 버튼이 위치한 모니터의 중앙을 우선 사용합니다. Windows SmartScreen은 운영 체제가 관리하는 보안 화면이므로 EdgeShot이 표시 위치를 지정하거나 우회하지 않습니다.

## 빌드

요구 사항: Windows x64, .NET 9 SDK

```powershell
dotnet build .\EdgeShot\EdgeShot.csproj -c Release
dotnet run --project .\EdgeShot.Tests\EdgeShot.Tests.csproj -c Release
dotnet publish .\EdgeShot\EdgeShot.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

배포 파일은 `EdgeShot\bin\Release\net9.0-windows\win-x64\publish\EdgeShot.exe`에 생성됩니다.

## 현재 제한

- Windows 보호 콘텐츠(DRM 영상 등)는 운영 체제 정책에 따라 검게 캡처될 수 있습니다.
- 실행 파일은 코드 서명되지 않았으므로 배포 환경에서는 조직 또는 게시자의 Authenticode 서명을 권장합니다.
